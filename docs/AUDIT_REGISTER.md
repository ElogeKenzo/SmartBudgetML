# Registre d'Audit — SmartBudget ML (v1.0 → v2.0, réaligné Phase 8)

Ce registre trace l'ensemble des constats de l'audit initial (`A1`–`A24`) ainsi que les constats issus de l'audit approfondi du code de `develop` en Phase 8 (`N1`–`N17`).  
Pour les métriques, comptes de tests et résultats des garde-fous automatiques, voir [`docs/generated/STATUS.md`](generated/STATUS.md).
